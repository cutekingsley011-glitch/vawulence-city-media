PAYSTACK INTEGRATION SETUP:

- Store Paystack public/secret keys and the subaccount code as environment variables/secrets — do not hardcode them

UNIFIED TRANSACTION LEDGER (new Supabase table, used by everything below):

- Admin dashboard gets a new "Transactions" page showing every transaction in plain language, e.g. "Chidinma paid ₦10,500 → ₦10,000 for [Event Name] ticket + ₦500 service fee" — filterable by type

- events table: (id, title, description, image_url, venue, event_date, restriction_tags [e.g. "18+", "Female Only", "Male Only" — multi-select], is_paid [boolean], ticket_price [nullable if free], status [upcoming/past, can be auto-calculated from event_date], created_at)

- Ticket card displays on-screen immediately after payment, with a "Save to Gallery / Screenshot" friendly layout
- Log the purchase in the transactions table
- Admin sees, per event: total tickets sold, total revenue, list of buyers

ADS / PROMOTION:
