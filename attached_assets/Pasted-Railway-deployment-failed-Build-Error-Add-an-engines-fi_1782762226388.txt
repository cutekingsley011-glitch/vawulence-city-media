## Problem
The build fails at the `pnpm --filter @workspace/vcm run build` step because Nixpacks defaults to Node.js 18.20.5, but the project requires Node.js 20+.

Build log errors:
```
You are using Node.js 18.20.5. Vite requires Node.js version 20.19+ or 22.12+. Please upgrade your Node.js version.
Error: Cannot find native binding. (@tailwindcss/oxide@4.3.0)
```

The builder is Nixpacks (set in `railway.toml` via `[build] builder = "NIXPACKS"`). The build command (`pnpm install --frozen-lockfile && pnpm run typecheck:libs && pnpm --filter @workspace/vcm run build && pnpm --filter @workspace/api-server run build`) comes from `railway.toml`.

## Diagnosis
Nixpacks selects the Node.js version based on the `engines` field in `package.json` or a `.node-version` file. Neither exists in this repository, so Nixpacks defaults to Node.js 18. The project uses Vite 7.3.3 (requires Node.js 20.19+) and @tailwindcss/oxide 4.3.0 (requires Node.js 20+ for native bindings). The Node.js 18 runtime cannot run these packages. The previous deployment (39e94099) failed with the identical error, confirming this is pre-existing and not caused by the latest commit.

## Fix
1. **File:** `package.json` (repo root)
2. **Current content (relevant section):**
```json
{
  "name": "workspace",
  "version": "0.0.0",
  "license": "MIT",
  "scripts": {
```
3. **Replacement:**
```json
{
  "name": "workspace",
  "version": "0.0.0",
  "license": "MIT",
  "engines": {
    "node": ">=20"
  },
  "scripts": {
```
4. **Why:** Adding `"engines": { "node": ">=20" }` tells Nixpacks to install Node.js 20+ instead of defaulting to 18. This satisfies both Vite 7.3.3's requirement for Node.js 20.19+ and @tailwindcss/oxide's requirement for Node.js 20+ native bindings.
